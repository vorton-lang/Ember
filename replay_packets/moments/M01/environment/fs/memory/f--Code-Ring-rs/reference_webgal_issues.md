type: reference
---

每月扫描以下两个仓库的 issue 区，筛选对 Ring-rs 有参考价值的功能需求：

- https://github.com/OpenWebGAL/WebGAL — 引擎核心
- https://github.com/OpenWebGAL/WebGAL_Terre — 编辑器（类似 ring-studio）

**Why:** WebGAL 用户群较大，issue 区积累了大量真实视觉小说创作者的需求。LaTeX 公式支持（RFC-045）就是从那边发现的。

**How to apply:** 每月扫描一次 open issues，筛选 非 bugfix 类 issue，评估是否适合 Ring-rs 引擎。有价值的想法记录为 Draft RFC 或 backlog。
